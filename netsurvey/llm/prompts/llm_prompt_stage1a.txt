        *   Log shows `Administratively Down` or similar -> `status: "admin_down"`
        *   Log shows `IPv4 State : Enabled` for an IP interface, and its link is up -> `protocol_status: "up"` (if link is down, protocol status might also be considered 'down' or follow operational status)
        *   Log shows `IPv4 State : Disabled` for an IP interface -> `protocol_status: "down"`

*   **VLAN Status (CRITICAL STANDARDIZATION for `vlans[].status`):**
